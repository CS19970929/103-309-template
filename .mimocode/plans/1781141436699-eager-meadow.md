## Key Findings from Exploration

### Project Identity
- BMS (Battery Management System) protection board firmware for **STM32F103C8** (Cortex-M3, 64KB Flash, 20KB RAM)
- AFE: **SH367309** (16-cell series)
- Built with **Keil MDK-ARM V5** (ARMCC V5.06), ST Standard Peripheral Library V3.5.0
- Single Keil `.uvprojx` at `103 + 309/Project/Users/CommomSH367309_16series_103RCT6_C.uvprojx`

### Build System
- **No command-line build scripts exist** — build is done via Keil IDE
- Two build targets: `Production` (Objects/) and `Debug_Trace` (Objects_DebugTrace/)
- After-build step runs `fromelf.exe --bin` to generate `.bin` from `.axf`
- `Clean.bat` in `103 + 309/Project/Users/` copies output .hex/.bin and cleans artifacts

### Firmware Architecture
- Entry: `main.c` → `InitDevice()` → `InitVar()` → while(1) loop
- Main loop tasks: `App_SysTime()`, `App_WarnCtrl()`, `APP_LedBar()`, `App_AFEGet()`, `App_Sci()`, `App_SOC()`, `App_BmsEUavcan()`, `App_SleepDeal()`, `App_FlashUpdate()`, `App_LogRecord()`
- IAP enabled: `_IAP` defined in main.h, APP starts at 0x8004800
- AFE type configured in `conf.h`: `#define AFE_TYPE sh36xx`
- Current range: `#define LEVEL_CURR CURR_150A`
- Compiler defines: `STM32F10X_MD, USE_STDPERIPH_DRIVER`

### Key Source Files
- `conf/conf.h` — Global config, AFE type, current range, feature flags
- `conf/conf_gpio.h` — GPIO pin mapping (PA0=WK_MCU, PA9=SOC_KEY, PB5=KEY1, PB15=DBG_LED, PA4=CMNT_EN)
- `main.c` — Entry point and main loop
- `System_Init.c` — Timer/NVIC/IWDG initialization, system time scheduler
- `SleepDeal.c` — Sleep mode management (Normal/Hiccup/Deep STOP modes)
- `SOC.c` — OCV-based SOC estimation with default lookup table
- `LedBar.c` — LED state machine (5-LED bar with L1 dual-color)
- `Can_HDX.c` — CAN bus handling with NART and retry logic
- `Bms_EUavcan.c` — EUAVCAN protocol broadcast

### Important Conventions
- Chinese comments throughout (team language)
- Mix of `UINT8/UINT16` (custom typedefs) and `uint8_t/uint16_t` (stdint)
- Custom types from `PubFunc.h`: `UINT8`, `UINT16`, `UINT32`, `UINT64`
- `_DEBUG_CODE` flag suppresses main loop when defined
- Backup domain (BKP) registers used for sleep state persistence
- EasyLogger library for debug logging (disabled in production via `#define log_i(...) ((void)0)`)
