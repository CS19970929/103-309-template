# 开关与休眠策略

PA9 短接为低电平，断开为高电平。通过 `Project_Config.h` 的 `PROJECT_CFG_SWITCH_MODE` 选择逻辑，无需修改业务代码；缺省为 1。

| 宏值 | 开关动作 |
| --- | --- |
| `0`（`PROJECT_SWITCH_MAINTAINED`） | 保持型：短接持续 RUN，断开稳定至少 50 ms 请求 NORMAL；休眠后短接稳定 50 ms 唤醒 |
| `1`（`PROJECT_SWITCH_PUSHBUTTON`，默认） | 按键型：按住 3 秒进入 NORMAL；NORMAL/DEEP 按住 1 秒唤醒，松手再按 3 秒才可休眠；HICCUP 短接中断立即唤醒，持续短接 3 秒即可进入 NORMAL |

RUN 用 10 ms 单调 tick 计算时长，重复调用不累计时间，输入抖动撤销本次计时。保持型短接沿用 PA9 活动阻止普通空闲休眠；断开进入 NORMAL。保留充电器唤醒：充电器输入有效期间允许保持 RUN，移除后若仍断开则再次计时进入 NORMAL，避免反复睡眠/充电唤醒。通信唤醒源沿用既有模式配置和有效帧验证，不覆盖保持型断开的休眠请求。

按键型 NORMAL 要求持续短接 1 秒才恢复 RUN，短按或确认期间松开继续休眠。唤醒后保留等待松手状态，当前按住多久都不再次请求 NORMAL；必须先松手，再重新连续短接 3 秒。

按键型 HICCUP 在实际开关中断且 PA9 仍为低电平时立即恢复 RUN，不等待 1 秒。RUN 外设与定时器恢复后立即开始 3 秒计时，持续短接满 3 秒即可进入 NORMAL，无需先松手；提前松手撤销本次计时。电流与开关同时唤醒时保留开关来源，单纯电流或通信唤醒不解除旧按住状态的松手要求。进入 NORMAL 后一直短接的旧电平和松手中断均不恢复 RUN，重新短接后仍需 NORMAL 的 1 秒确认。HICCUP 因空闲转成 NORMAL 后，按最终的 NORMAL 模式执行确认及松手规则。

DEEP 继续使用 1 秒确认及松手后重按规则；保持型各模式维持 50 ms 确认。保护性 DEEP 优先，不因保持型短接或充电判断而取消；若进入 DEEP 时已经短接，必须先断开再短接，不能把一直短接的旧电平视为新唤醒。充电器等原有有效唤醒源继续保留。

PA9 使用双边沿中断，以识别松手/断开。需要输入确认的模式在主流程中有界等待并按既有方式喂狗；按键型 HICCUP 开关中断跳过等待，仍保留确认过放的优先检查。ADC 在 STOP 与候选处理期间保持关闭，只有恢复 RUN 才按原顺序重新初始化、等待有效采样。旧 `_DI_SWITCH_*` 宏已移除，只有 `PROJECT_CFG_SWITCH_MODE` 决定策略。

DEEP 等待期间保留备份域休眠原因，只有按键确认成功后才清除；充电唤醒保留既有充电标志。等待中发生复位仍回到 DEEP 等待，不把复位当成用户唤醒。STOP 前后及按键确认期间按既有方式喂狗。

验证入口 `python tools/test_sleep_policy.py` 分别编译两个模式，使用实际 `SleepDeal.c`、`rtc_sleep.c`，以主机硬件替身覆盖 NORMAL 的 1 秒确认与松手再按、HICCUP 短接中断即时唤醒、恢复 tick 后连续短接 3 秒进入 NORMAL、电流同时唤醒、UART 验证期间按键中断、HICCUP 转 NORMAL 后的模式规则、持续短接与松手不回 RUN、DEEP、保持型断开/短接、抖动、tick 回绕及充电唤醒；实板按键、电流和 MOS 动作需单独验收。无 BIN 工程验证可用 `python tools/check_bms_no_bin.py --target FD_Release --switch-mode 0`（或 1），只覆盖临时工程的编译宏，不修改工作区配置。

验证与编译结果属于主机证据，不替代实板开关、低功耗及 MOS 动作验收。修改复用现有按键状态与时间戳，不增加常驻变量。

AFE 成功读取的 UV 状态新触发时，在本轮 SOC 计算后通过 `SOC_RequestSetOnce(0)` 同步清零容量、报告和快照，立即请求 DEEP，不等待秒节拍或原低压定时。RTC 周期和按键/串口候选唤醒也先检查 AFE UV，确认后直接执行保存、休眠日志、备份标志和复位，保持 ADC 关闭。

备份域使用 `0x1238` 表示已经处理过放的 DEEP，沿用 DR2/DR3 互反校验，不增加 Flash 标志页。这种软件休眠复位不计入普通重启次数。按键或充电器唤醒后保留过放已处理状态，允许显示 SOC=0 并充电；该状态只抑制同一次 UV 再次立即请求 DEEP，不屏蔽既有休眠入口。唤醒后强制低压 60 秒、`u16Sleep_Vlow` / `u16Sleep_TimeVlow` 参数低压定时、空闲、开关及上位机休眠继续按原条件生效，满足条件仍可再次休眠。仅新的有效 AFE 读取确认 UV 已恢复后，才允许下一次 UV 再立即触发。客户关放电 MOS、其他放电保护或单次低电压读数均不作为已确认过放。

连续无充放电、外部通信及按键活动达到 `OtherElement.u16Sleep_TimeNormal` 分钟后自动进入 NORMAL，两个电池化学体系的默认表均为 `10080` 分钟（7天）。`u16Sleep_VNormal` 保留地址和数据含义，不参与条件。保留现有电流有效门限；通信、Flash/升级忙或 AFE 数据异常不作为空闲证据，CAN 自身周期广播不计作外部活动。串口有效帧直接重置起点，CAN 活动沿用接收计数及忙状态检测。

用 RTC 无符号时间差衡量空闲，跨 HICCUP/STOP 累计，不依赖恢复后重新启动的 RUN tick。期限到达时直接切为 NORMAL，拉低 CTLC 并重设唤醒源，ADC 保持关闭；最终有效唤醒后恢复 CTLC 与外设。复位后重新开始空闲计时，不写额外 Flash 周期计数。现有已保存的 `u16Sleep_TimeNormal` 按其实际值生效，不强制改写为默认值。
