# 纯安时积分 SOC

当前实现集中在 `103 + 309/Project/Source/SOC.c`；`SocEnhance.c/h` 已删除。本文对应 2026-11-12 的精简结果。

## 计算和状态所有者

`SOC.c` 独占当前容量、额定容量、累计等效放电循环和积分余数。`App_AFEGet()` 每 200 ms 完成 AFE 采样后调用 `App_SOC()`；仅 `Fault_IsCurrentSampleFresh()` 有效时，将 `AfeCurrent_GetCurrent_mA()` 的校准后有符号 mA 积入容量，充电为正、放电为负。AFE 本身的电流零点和 K/B 测量校准保持原实现，不属于本次移除的 SOC 校准。

容量内部单位为 0.1 A*s，200 ms 积分保留 mA*ms 余数；中间运算使用 64 位，容量钳位于 `[0,额定容量]`。协议容量仍为 Ah*100，SOC 为容量比例四舍五入的整数百分比；积分可自然达到 0/100，不再设置充电 99% 上限。SOC 四舍五入为 0 或 100 时，内部仍可能保留不足半个百分点的容量差。

已移除：启动查电压、满充电压锚点、低电量尾段追低、RTC/静置 OCV、压降保持、板端自耗和 Type-C 等效电流。电压、温度、充电器接入及保护事件不再直接改写 SOC；无效采样、STOP 期间暂停积分，不按旧电流推算。

SOH 保留原循环估算：每累计 100 次等效放电循环下降 1%，最低 80%；SOH 独立上报，不衰减 SOC 的额定容量。累计循环在充电时不回退，整数运算饱和；不实现实际容量学习。

## 初始化和外部写入

- 无有效 V2 快照时使用用户确认的 60%，与电压无关；首次保存失败仍保留待保存状态并重试。
- 有有效快照时恢复容量比例、小数容量、循环数和放电累计余量；旧快照曾按 SOH 衰减满容量时，按保存的容量比例恢复到当前额定容量，避免升级后 SOC 突跳。退休的校准标志忽略并在下次保存时写零。
- `0x1005` 保留手动设置 SOC：范围 0～100，必须保存成功后才发布；失败返回原有错误码并保持原 RAM 状态。
- `0x2318` 额定容量改变时保留当前容量比例，不重置累计循环；只有明确写 `0x2319` 循环参数或显式参数初始化时，才使用指定循环数。
- `0x231A/0x231B` 满/空电压、`0x230C` 曲线选择及 `0x2200` 历史只读表保留协议和存储布局，但不参与 SOC 计算。修改这些电压字段不再重载 SOC 或重置循环。
- 改保护参数、写入失败回滚均不再重新初始化 SOC。

## 保存和休眠

沿用 V2 快照、CRC、提交标记、序号和 Flash 页地址。普通运行在整数 SOC 或完整循环变化时保存；不因 0.01 次循环变化额外写一次。保存失败按真实 10 ms tick 每秒最多重试一次，支持 tick 回绕；不会按主循环速度擦写。

手动 NORMAL 和 DEEP/复位休眠前强制保存完整容量。自动 HICCUP 保留 RAM，避免每次空闲 STOP 强制写入。确认 AFE UV 仍按原保护流程立即请求 DEEP，但不再清零 SOC。正常快照间突然断电可能回退到上次成功保存的不足一个百分点；积分的不足 0.1 A*s 余数不进入原 V2 布局。

参数版本和升级初始化策略保持原配置，本次不修改软件版本字符串，不主动清空已出货参数、SOC、日志或统计。已被旧算法错误扣低的 SOC 不会自动补回，应在确认实际电量后通过保留的手动设置接口建立正确起点。

## 验证入口和结果

`python tools/run_soc_host_c_test.py` 直接编译当前 `SOC.c`，并运行实际参数写入、手动 SOC 命令和休眠保存代码。`python tools/soc_replay_test.py` 转到同一真实 C 验收入口；图形测试工具使用纯积分参考模型，不能替代固件 C 验证。

16 组真实 C 回归覆盖：无快照 60%、14 种电压不影响积分、正负 mA 与小电流余数、客户放电场景、0/100 钳位、手动设置和恢复、72 小时零电流、无效采样、旧快照比例、真实参数写入及失败回滚、首次/运行保存失败及真实超时、NORMAL/HICCUP/DEEP、SOH 边界、容量和电流极值、20 万次随机序列与独立 mA*ms 基准、快照格式及写频。

24.5 Ah 从 100% 开始，1.1 A 放电 30 分钟后为 98%；再以 6 A 放电两小时后为 49%、剩余 11.95 Ah。SOH 为 80% 时仍按同一额定容量积分。一次放空和再充至 99% 的快照调用由约 299 次降到 200 次；不是 Flash 寿命验收结论。

同时运行 `tools/test_storage.py`、`tools/test_uart_protocols.py`、`tools/test_sleep_policy.py`、`tools/test_protection_refactor.py` 和电流 K/B host 回归。Release/Debug 使用 `tools/check_bms_no_bin.py`，只在用户临时区生成 AXF/MAP，检查 App `[0x08004800,0x0801C000)` 边界，不生成 BIN/HEX，不烧录。

主机桩和编译不代表实板电流精度、真实掉电、Flash 寿命或充放电验收；板上应复核电流零点、K/B、24.5 Ah 参数、长按关机恢复和至少一次受控充放电。
