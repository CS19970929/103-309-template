# SH367309 启动电流校准

实现位于 `DataDeal.c`。普通上电、MCU 复位和深睡复位使用相同路径：关闭 CTL，开启 CADC、关闭 CHG/DSG/PCHG 许可，回读 CONF 与 BSTATUS3 确认 FET 关闭。两笔 CADC 采样各等待 300 ms，采样前后继续核实关闭条件。

当前源码的两笔绝对值上限为 65 count，差值上限为 15 count；超出范围或寄存器操作失败时不应用零偏。成功零偏采用 `(raw1 + raw2) * 2`，单位为 raw×4；运行电流先扣零偏，再按原充/放电 K/B 进行校准。校准状态为 VALID 或明确失败状态后，本次 MCU 运行中的 AFE 重初始化不重新学习。具体读失败分支以源码为准。

内部输出为有符号 mA，协议充/放电电流保持 A×10。`CURRENT_DEADBAND_MA` 保持当前源码配置（当前为 0）；此次清理不调整采样、校零门限、K/B 或电流缩放。

`0xC100`～`0xC10F`、V25～V32 临时诊断覆盖、原始 CADC 调试注入及相关缓存已移除。实际单体数组和报文均使用真实电压，不存在串位发送 61001；原报告长度、故障原因和保留字位置不变。

保留 `__VIRTURE_CURRENT__`：默认未定义。启用编译后，仅当 `sys_time.isdebugenable == 1` 时，以 `sys_time.CHG/DSG`（A×10）覆盖协议电流，并以二者差值换算有符号 mA。关闭该运行开关后恢复真实采样。`sys_time` 其余既有普通成员也保留。

验证：`python -B tools/run_current_calibration_host_c_test.py` 运行真实 K/B、启动校准与采样函数，同时覆盖虚拟电流关闭/开启构建。host 结果不代表真实零漂、温漂、采样周期或板上电流精度验收。
