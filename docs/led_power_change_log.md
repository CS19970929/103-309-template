# LED/按键/电源修改记录

日期：2026-05-27

## 本次重构

- 重写 `LedBar.c/.h`，移除旧开机、充电、关机分散分支，改为统一运行态 LED 状态机。
- 新增 `PowerUi.c/.h`，将开机确认、关机请求、MOS force 和 AFE_Sleep 入口从 LED 中断显示逻辑中拆出。
- 新增 `LedSnapshot.c/.h`，用备份域保存休眠前 SOC 和报警状态。
- 新增 `SleepWakeFastUi.c/.h`，在 STOP 唤醒后、完整初始化前提供按键快显窗口。
- 修改 `SleepDeal.c`，睡眠前保存 LED 快照，并在 STOP 唤醒后优先处理 PA9 快显和 PA0 充电唤醒。
- 修改 `RTC.c`，避免每次 RTC 配置都清备份域。
- 修改 `main.c`，主循环处理电源请求，初始化后按确认状态设置 MOS force。
- 修改 Keil 工程文件，加入新增源文件。

## 行为变化

- 休眠态按一下不再等待完整系统初始化，直接显示上次 SOC。
- 长按确认从旧逻辑的 4 秒改为 3 秒。
- 开机/关机超时统一为 8 秒。
- 充电显示由旧“25/50/75/100 档位下一灯闪烁”改为截图要求的 20/40/60/80/100 档位下一档闪烁。
- 关机不再在确认阶段提前关闭 DSG，改为动画结束后 CHG/DSG 一起关闭并进入 AFE_Sleep。
