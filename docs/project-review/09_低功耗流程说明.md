# 09 — 低功耗流程说明

## 休眠模式定义

**源文件**: `rtc_sleep.h:25-28`

| 模式 | 枚举值 | MCU 状态 | 唤醒源 | 适用场景 |
|------|--------|---------|--------|---------|
| `NO_SLEEP` | 3 | 全速运行 | — | 正常工作状态 |
| `NORMAL_MODE` | 0 | 软件复位 + STOP | 充电器 / 按键 | 常规空闲后休眠 |
| `HICCUP_MODE` | 1 | STOP (RTC 闹钟周期唤醒) | RTC 闹钟 / 充电器 / 按键 | 间歇式低功耗 |
| `DEEP_MODE` | 2 | 软件复位 + 深度 STOP | 充电器 / 长按键 | 过放保护后深度休眠 |

## 休眠阻止条件 (LP_BLOCK)

**源文件**: `rtc_sleep.h:29-39`

`LP_GetBlockReason()` 在每个 1s 周期检查以下条件，任一位为 1 则**阻止进入休眠**：

| 位掩码 | 标志 | 检查函数 | 阻止条件 |
|--------|------|---------|---------|
| `0x001` | LP_BLOCK_CHARGE | `CheckChargeMa()` | 充电电流 > 10mA |
| `0x002` | LP_BLOCK_DISCHARGE | `CheckDischargeMa()` | 放电电流 > 10mA |
| `0x004` | LP_BLOCK_COMM | `CheckCommBusy()` | SCI/CAN 端口忙 |
| `0x008` | LP_BLOCK_KEY | `CheckKeyActive()` | 按键按下中 |
| `0x010` | LP_BLOCK_EXT_COMM | (外部计数器) | 最近有上位机通信 |
| `0x020` | LP_BLOCK_FLASH_BUSY | `CheckFlashBusy()` | Flash 写入中 |
| `0x040` | LP_BLOCK_UPGRADE | `CheckUpgrade()` | 固件升级标志有效 |
| `0x080` | LP_BLOCK_FAULT | `CheckFault()` | **任何三级故障有效** |
| `0x100` | LP_BLOCK_LED_ACTIVE | `CheckLedActive()` | LED 动画播放中 |
| `0x200` | LP_BLOCK_AGING | — | 工厂老化运行中（定义但未在 block 检查中使用） |

## 休眠状态机

**主入口**: `rtc_sleep()` (`rtc_sleep.c:248`)

**调用频率**: 主循环每轮，但仅在 1s 周期内执行实际逻辑。

### 休眠请求判定 (`lp_update_sleep_request()`)

```
1. 检查低电压强制深度休眠:
   if (Vmin ≤ 2800mV && 无充电电流)
       → 强制请求 DEEP_MODE

2. 检查正常休眠条件:
   block = LP_GetBlockReason()
   if (block == 0) {
       idle_seconds++
       if (idle_seconds ≥ time_enter_rtc)
           → 请求 HICCUP_MODE
   } else {
       idle_seconds = 0
   }
```

### 各模式处理

#### NORMAL_MODE / DEEP_MODE

```
1. low_power_log_and_commit_sleep()  → 保存状态到日志
2. SleepDeal_Continue(mode)          → 写入 Boot Flag + 复位
3. (复位后) SleepDeal_HandleBootSleepStartup()
   ├── 读取 BKP Boot Flag
   ├── 配置 STOP 模式 IO
   ├── 进入 STOP 模式
   └── 等待有效唤醒源
```

#### HICCUP_MODE

```
1. rtc_sleep_prepare_rtc()
   ├── SOC_SaveSnapshotBeforeSleep()
   ├── Can_PrepareSleep()
   ├── LED 显示 SOC
   └── 配置 RTC 闹钟 (~10s)

2. while (rtc_sleep_run_hiccup_cycle())
   ├── RtcSleep_PortEnterStop()  → MCU 进入 STOP
   ├── (RTC 闹钟 ~10s 后唤醒)
   ├── 检查唤醒有效性:
   │   ├── 无故障? 继续
   │   ├── 无电流? 继续
   │   └── 无效唤醒? 退出循环, 恢复运行
   ├── 累加休眠时间
   ├── SOC_ApplyRtcRelaxationCompensation()
   └── FactoryAging_ApplySleepTime()
```

> **性能风险**: HICCUP 模式下 `while` 循环**阻塞主循环**（见 `rtc_sleep.c:285-287`），期间 CAN 和 RS485 都无法响应。

## Boot Flag 系统

**源文件**: `SleepDeal.c`

### Boot Flag 存储

Boot Flag 存储在**备份寄存器** `BKP_DR2/DR3`（软件复位保留）和 Flash `0x0801FC00`。

| 值 | 含义 | 设置时机 |
|-----|------|---------|
| `0x1234` | NORMAL 休眠 | `SleepDeal_Continue(NORMAL_MODE)` |
| `0x1235` | DEEP 休眠 | `SleepDeal_Continue(DEEP_MODE)` |
| `0x1236` | HICCUP 休眠 | `SleepDeal_Continue(HICCUP_MODE)` |
| `0x1237` | 充电器唤醒 | 充电器插入时 |
| `0xFFFF` | 正常上电 | 正常上电复位 |

### 启动时的休眠恢复 (`SleepDeal_HandleBootSleepStartup()`)

```
读取 BKP Boot Flag:
├── 0x1236 (HICCUP) → 进入 STOP 等待充电器/按键唤醒
├── 0x1234 (NORMAL) → 进入 STOP (Normal IO 配置)
├── 0x1235 (DEEP)   → 进入 STOP (Deep IO 配置)
├── 0x1237 (充电器) → 直接处理充电器唤醒 (不进入 STOP)
└── 0xFFFF (正常)   → 标准启动流程
```

### 唤醒有效性验证 (`SleepDeal_IsWakeupValid()`)

```
条件（任一满足即有效）:
1. 充电器插入 (PA0 检测到高电平)
2. 按键按下 ≥ 500ms (含 SOC 预览 LED 显示)
```

## RTC 时钟源

**源文件**: `RTC.c:426` (`Init_RTC()`)

```
优先级:
1. LSE (外部低速晶振 32.768kHz) — 高精度
2. LSI (内部低速振荡器 ~40kHz)   — 低精度，备用
```

- LSE 启动超时: `LSE_START_TIMEOUT` (具体值待确认)
- 预分频器: 32767 (产生 1Hz RTC 时钟)
- RTC 闹钟: 配置为 ~10s 后唤醒 (HICCUP 模式)
