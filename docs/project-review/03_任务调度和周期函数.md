# 03 — 任务调度和周期函数

## 调度模型

裸机大循环 + 时间标志驱动。无 RTOS，无抢占式调度。

## 系统时基 (System Tick)

**源文件**: `System_Init.c:324` (TIM3_IRQHandler), `System_Init.h:56-66`

| 时间标志 | 来源 | 周期 |
|---------|------|------|
| `b1Sys10msFlag` | TIM3 中断 | 10ms |
| `b1Sys50msFlag` | TIM3 中断（累加） | 50ms |
| `b1Sys100msFlag` | TIM3 中断（累加） | 100ms |
| `b1Sys200msFlag` | TIM3 中断（累加） | 200ms |
| `b1Sys1000msFlag` | TIM3 中断（累加） | 1s |

**锁存机制**: ISR 设置标志位，`SysTime_LatchTaskFlags()` 在主循环开头读取。这避免了 ISR 和主循环之间的竞态条件。

**10ms Tick 计数**: `SysTime_Get10msTickCount()` 提供从启动以来的 10ms 滴答数（原子读取，关中断保护）。

## 各模块的周期任务

### 10ms 级别

| 模块/任务 | 函数 | 周期判断方式 |
|----------|------|------------|
| RS485 帧处理 | `Sci_PortPoll_10ms()` | 通过 `b1Sys10msFlag` 判断 |
| CAN 轮询 | `CanIap_10msTask()` (IAP 中) | 通过 10ms 标志 |
| ADC 定时 | TIM2 CC2 触发 (10kHz) | 独立硬件定时器 |

### 200ms 级别（主要任务周期）

| 模块 | 入口函数 | 功能 |
|------|---------|------|
| AFE 数据采集 | `App_AFEGet()` → `DataLoad_CellVolt()` + `DataLoad_Temperature()` + `DataLoad_Current()` | I2C 读 AFE 寄存器，更新 `g_stCellInfoReport` |
| AFE 监控 | `MonitorAFE()` | AFE 通信错误检测和恢复 |
| SW 保护 | `new_todo_logi()` | MCU 软件层独立的 OVP/OTP 检测 |
| SOC 计算 | `App_SOC()` → `SOC_IntEnhance_Ctrl()` | 安时积分 + 校准判断 |
| ADC 采样 | `App_AnlogCal()` | 总压、TypeC 电流、温度 ADC 计算 |
| 充电检测 | `charger_detect_and_keyLogi_200ms()` | 5V 充电器插入/拔出检测 |
| CBC 均衡 | `App_CBC()` | 电池均衡控制 |
| 看门狗喂狗 | `Feed_IWatchDog` | IWDG 重装载 |

### 800ms 级别

| 模块 | 函数 | 功能 |
|------|------|------|
| 日志记录 | `App_LogRecord()` 内部 | 事件日志写入 Flash |

### 1s 级别

| 模块 | 函数 | 功能 |
|------|------|------|
| 休眠判断 | `rtc_sleep()` → `lp_update_sleep_request()` | 1 秒周期检查是否满足休眠条件 |

| CAN SOC 帧 | `CanFeidao_SendSoc1000ms()` | 1s 周期发 SOC CAN 帧 |
| SOC 发布 | `SOC_PublishReportData()` | 将内部 SOC 状态拷贝到上报结构体 |

### 5s 级别

| 模块 | 函数 | 功能 |
|------|------|------|
| CAN 容量帧 | `CanFeidao_SendCap5000ms()` | 5s 周期发容量 CAN 帧 |
| CAN SOH 帧 | `CanFeidao_SendSoh5000ms()` | 5s 周期发 SOH CAN 帧 |
| CAN 版本帧 | `CanFeidao_SendVersion5000ms()` | 5s 周期发版本 CAN 帧 |
| CAN 状态帧 | `CanFeidao_SendStatus5000ms()` | 5s 周期发状态 CAN 帧 |
| CAN 老化帧 | `CanFeidao_SendFactoryTime5000ms()` | 5s 周期发老化时间 CAN 帧 |

### 按需/事件驱动

| 模块 | 触发条件 |
|------|---------|
| Flash 参数保存 | RS485 写命令 → `EEPROM_SaveRWParametersToFlash()` |
| Flash 日志写入 | 事件发生 → 下一轮 `App_LogRecord()` 批量写入 |
| CAN 应用命令 | CAN 中断接收 → 下一轮 `App_Can()` 处理 |
| 固件升级跳转 | RS485/CAN 升级命令 → `AppUpgrade_RequestIap()` → `MCU_RESET()` |
| 工厂老化完成 | `FactoryAging_Task()` 检测时间达标 |

## 任务执行顺序依赖

```
SysTime_LatchTaskFlags()     ← 必须在所有任务前
    ↓
FactoryAging_Task()          ← 可能控制 MOS 状态
    ↓
APP_LedBar()                 ← 显示
    ↓
App_AFEGet()                 ← I2C 读 AFE → 更新 g_stCellInfoReport
    ↓                          ↓ 后续任务依赖此数据
App_CommonUpper()            ← RS485：使用 AFE 数据响应上位机
    ↓
App_AnlogCal()               ← ADC 处理：电流/电压/温度
    ↓
rtc_sleep()                  ← 可能进入 STOP 模式（阻塞）
    ↓
App_Can()                    ← CAN 发送：使用最新数据
    ↓
App_FlashUpdate()            ← Flash 更新标志检查
    ↓
App_LogRecord()              ← 日志写入
    ↓
App_ProID_Deal()
    ↓
Feed_IWatchDog               ← 最后喂狗
    ↓
DBG_Task()                   ← 调试（Release 时空）
```

## 临界区保护

| 机制 | 文件 | 用途 |
|------|------|------|
| `__disable_irq() / __enable_irq()` | `System_Init.c` | `SysTime_Get10msTickCount()` 读取时原子保护 |
| 非抢占主循环 | `Runtime.c` | 所有任务天然互斥，不需要互斥锁 |
| ISR → 主循环数据传递 | `SysTime_LatchTaskFlags()` | 通过 volatile 标志 + 主循环锁存，避免竞态 |

> **待确认**: 是否有其他 ISR 直接修改全局变量而没有被 `volatile` 保护的情况？`g_stCellInfoReport` 在 AFE I2C 中断路径中被写入，同时主循环也在读。需要确认是否所有写入发生在主循环的 `App_AFEGet()` 中而非 ISR。
