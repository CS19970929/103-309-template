## 关键位域结构

### MDLCHGFAULT_REG (故障标志位域)

**源文件**: `Sci_Upper.h:33-60`

```c
union MDLCHGFAULT_REG {
    UINT16 all;
    struct MDLCHGFAULT_BITS {
        UINT16 b1CellOvp       :1;   // 单体过压
        UINT16 b1CellUvp       :1;   // 单体欠压
        UINT16 b1BatOvp        :1;   // 总压过压
        UINT16 b1BatUvp        :1;   // 总压欠压
        UINT16 b1IchgOcp       :1;   // 充电过流
        UINT16 b1IdischgOcp    :1;   // 放电过流
        UINT16 b1CellChgOtp    :1;   // 充电过温
        UINT16 b1CellDischgOtp :1;   // 放电过温
        UINT16 b1CellChgUtp    :1;   // 充电欠温
        UINT16 b1CellDischgUtp :1;   // 放电欠温
        UINT16 b1VcellDeltaBig :1;   // 压差过大
        UINT16 b1TempDeltaBig  :1;   // 温差过大 (Res)
        UINT16 b1SocLow        :1;   // SOC 低
        UINT16 b1TmosOtp       :1;   // MOS 过温
        UINT16 b1Rcved1/2      :1;   // 保留
    } bits;
};
```

### System_Status (系统运行状态)

**源文件**: `System_Monitor.h:152-184`

32 位系统状态：
- `b1StartUpBMS` — BMS 首次启动标记
- `b1Status_MOS_PRE/CHG/DSG` — 预充/充电/放电 MOS 状态
- `b1Status_AFE1/2` — AFE 状态
- `b1Status_Balance` — 均衡运行状态
- `b1Status_ToSleep` — 准备休眠
- `b4Status_ProjectVer` — 项目版本 (4-bit)

## 数据流图

```
AFE (SH367309)
  │ I2C (软件 TWI, 200ms周期)
  ├── SH367309_Read_AFE1 (原始测量值)
  │     └── DataDeal.c (校准 + 聚合)
  │           ├── g_stCellInfoReport.u16VCell[]  (单体电压)
  │           ├── g_stCellInfoReport.u16Temperature[] (温度)
  │           └── g_stCellInfoReport.u16Ichg/IDischg (电流)
  │
  ├── Registers_AFE1 (状态寄存器)
  │     └── Fault_ChangeToMCU()
  │           └── g_stCellInfoReport.unMdlFault_Third
  │
  └── MTP 配置写入
        └── SH367309_Reg_Store
              └── Refresh_Parameters()
                    ├── PRT_E2ROMParas (保护阈值来源)
                    └── OtherElement (均衡/SOC/系统参数来源)

g_stCellInfoReport ───→ Sci_Upper.c (RS485 上报)
                   ───→ CanFeidaoFrames.c (CAN 周期帧)
                   ───→ rtc_sleep.c (休眠判断)
                   ───→ LogRecord.c (日志记录)
                   ───→ SystemDebug.c (调试)
```
