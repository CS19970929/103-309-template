## 主 BMS 源码 (`103 + 309/Project/Source/`)

### 按功能分组

#### 入口与调度
| 文件 | 作用 |
|------|------|
| `main.c` | 程序入口，极简 while(1) 循环 |
| `main.h` | 中央包含文件，所有模块通过它互相引用 |
| `Runtime.c/.h` | 启动序列 `Runtime_Boot()` + 主循环调度 `Runtime_RunOnce()` |

#### 系统初始化
| 文件 | 作用 |
|------|------|
| `System_Init.c/.h` | 时钟、NVIC、定时器、IWDG、GPIO、位带操作宏、SYS_TIME 时基 |
| `StartupDefaultHandler.c` | 默认弱中断处理函数 |
| `ShortFunc.c/.h` | 短路保护初始化 |

#### 配置系统 (`conf/`)
| 文件 | 作用 |
|------|------|
| `conf/Project_Config.h` | 用户配置（Keil Configuration Wizard 可视化编辑） |
| `conf/conf.h` | 配置翻译层（PROJECT_CFG_* → legacy #define） |
| `conf/conf_gpio.h` | GPIO 引脚定义（完整硬件引脚映射） |
| `conf/conf.c` | GPIO 初始化、唤醒源配置、STOP 模式进入 |
| `conf/Project_BuildGuard.h` | 编译时验证（范围检查 + Release 排除调试） |

#### AFE 接口
| 文件 | 作用 |
|------|------|
| `I2C_AFE1.c/.h` | 软件模拟 I2C（TWI），SH367309 的底层读写 |
| `SH367309_Func.c/.h` | SH367309 功能函数：初始化、MOS 控制、故障读取、寄存器配置 |
| `SH367309_DataDeal.c/.h` | SH367309 特定数据处理：参数刷新、MTP 写入、查表 |
| `rtc_sleep_afe_port.h` | AFE 休眠操作抽象端口 |
| `rtc_sleep_afe_sh367309.c` | SH367309 特定休眠模式处理 |

#### 数据处理
| 文件 | 作用 |
|------|------|
| `DataDeal.c/.h` | 核心数据处理：电压/电流/温度采集、校准、AFE 监控、SW 保护 |
| `ADC.c/.h` | ADC 采样驱动（DMA + TIM2 触发）、测量值转换 |
| `PubFunc.c/.h` | 公共工具函数 |

#### SOC 算法
| 文件 | 作用 |
|------|------|
| `SOC.c/.h` | SOC 入口：初始化、App_SOC()、净电流计算 |
| `SocEnhance.c/.h` | 核心 SOC 算法：安时积分、OCV/满充/低尾/静置校准 |

#### 通信
| 文件 | 作用 |
|------|------|
| `Sci_Upper.c/.h` | RS485 Modbus-like 协议：寄存器读写、SCI 端口管理、IRQ 处理 |
| `Can_HDX.c/.h` | CAN 总线驱动：Feidao 协议、应用指令处理 |
| `CanFeidaoFrames.c/.h` | CAN 周期性数据帧（电压/电流/SOC/SOH/状态/版本/老化时间） |

#### 保护系统
| 文件 | 作用 |
|------|------|
| `Fault.c/.h` | 三级故障定义、阈值参数、故障记录 |
| `FaultSnapshot.h` | 备份寄存器存储的故障原因码（HardFault/MemManage/BusFault/UsageFault） |

#### 低功耗

|------|------|
| `rtc_sleep.c/.h` | 休眠状态机：请求、进入、唤醒、模式调度 |
| `SleepDeal.c/.h` | 休眠/唤醒处理：Boot Flag、唤醒有效性验证 |

## STM32 标准外设库

位于 `103 + 309/Project/STM32F10x_StdPeriph_Lib_V3.5.0/`：
- `drivers/`: CMSIS 核心文件 + 启动文件 + 系统时钟
- `inc/`: 外设头文件（gpio, usart, tim, adc, i2c, spi, can, rtc, pwr, bkp, iwdg, dma 等）
- `src/`: 外设源文件

**注意**: `drivers/stm32f10x_it.c` 为自定义中断处理文件（含 NMI、HardFault、SysTick、USART1-3、EXTI0-15），非 ST 原始模板。
