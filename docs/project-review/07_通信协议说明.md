# 07 — 通信协议说明

## 通信架构

BMS 支持 **三路通信接口**：

| 接口 | 物理层 | 协议 | 角色 | 用途 |
|------|--------|------|------|------|
| SCI1 | USART1 (PB6/PB7) | Modbus-like | Host | 上位机 RS485 通信 |
| SCI2 | USART2 | Modbus-like | 待确认 | 预留 |
| SCI3 | USART3 | Modbus-like | 待确认 | 预留 |
| CAN1 | CAN (PB8/PB9) | 飞道私有协议 | — | 外部系统通信 (BMS 间、APP) |

## RS485 协议 (SCI1)

**源文件**: `Sci_Upper.c/.h`

### 物理层

| 参数 | 值 |
|------|-----|
| 波特率 | 待确认 (Keil 工程配置) |
| 数据位 | 8 |
| 校验 | CRC16 (Modbus) |
| 从机地址 | 0x01 |
| 广播地址 | 0x00 |

### 帧结构

```
| 地址 | 功能码 | 寄存器地址 | 数据长度 | 数据 | CRC16 |
| 1B   | 1B     | 2B         | 2B       | NB   | 2B    |
```

### 功能码

| 功能码 | 常量 | 含义 |
|--------|------|------|
| 0x03 | `RS485_CMD_READ_REGS` | 读多个保持寄存器 |
| 0x06 | `RS485_CMD_WRITE_REG` | 写单个寄存器 |
| 0x10 | `RS485_CMD_WRITE_REGS` | 写多个寄存器 |

### 寄存器地址空间

**源文件**: `Sci_Upper.h` (地址映射宏), `Sci_Upper.c` (实际处理函数)

| 地址范围 | 区名称 | 访问 | 内容 |
|---------|--------|------|------|
| `0x1000-0x10FF` | 复位/单写 | W | 系统复位、功能开关、SOC 设置、老化控制 |
| `0x1100-0x11FF` | 功能开关 | W | BMS 功能模块的 ON/OFF 控制 |
| `0x2000-0x20FF` | 校准系数 | R/W | 每通道 K/B 校准系数 (47 通道) |
| `0x2100-0x21FF` | 保护参数 | R/W | 三级保护 13 类 × 5 参数 (65 字) |
| `0x2200-0x22FF` | SOC 表 | R/W | OCV-SOC 映射表、铜损系数 |
| `0x2300-0x23FF` | 其他参数 | R/W | 均衡、电流、休眠、SOC、系统参数 (32 字) |
| `0xC000-0xCFFF` | 扩展区 | R/W | LCD、RTC、序列号、事件记录、老化状态 |
| `0xD000-0xD0FF` | 只读报告 | R | `g_stCellInfoReport` 全部数据 (63 字) |
| `0xD100-0xD1FF` | RTC 值 | R | RTC 时间 |
| `0xD200-0xD2FF` | 故障快照 | R | 上次复位故障原因 |
| `0xFFF0-0xFFFF` | 系统信息 | R/W | 序列号、硬件/软件版本、Flash 连接 |

### 0x03 读寄存器处理流程

**源文件**: `Sci_Upper.c:293` (`Sci_Deal_ReadRegs_0x03()`)

```
1. 确定地址窗口 (线性 if-else 链匹配)
2. 计算窗口内偏移
3. 验证地址范围有效性
4. 从对应数据结构构造响应帧
5. 发送响应（含 CRC16）
```

### 0x06 写单寄存器处理

**源文件**: `Sci_Upper.c:386` (`Sci_Deal_WrReg_0x06()`)

支持的命令：
- **复位命令** (0x1000+): 校准系数复位、保护参数复位、保护记录清除
- **功能开关** (0x1100+): BMS 各子功能 ON/OFF
- **SOC 操作**: 设置 SOC 一次值、SOC 容量复位
- **老化控制**: 老化时间复位、老化时长设置
- **CAN 地址**: 设置 CAN 通信地址

### 0x10 写多寄存器处理

**源文件**: `Sci_Upper.c:784` — 根据地址分发到各处理函数：

| 处理函数 | 寄存器区 |
|---------|---------|
| `Sci_WrRegs_0x10_CalibCoef()` | 校准系数（空函数） |
| `Sci_WrRegs_0x10_Protect()` | 保护参数（含快照回滚） |
| `Sci_WrRegs_0x10_SocTable()` | SOC 表（返回不支持） |
| `Sci_WrRegs_0x10_RTC()` | RTC（空函数） |
| `Sci_WrRegs_0x10_Balance()` | 均衡参数 |
| `Sci_WrRegs_0x10_SysOther()` | 系统其他参数 |
| `Sci_WrRegs_0x10_SleepElement()` | 休眠参数 |
| `Sci_WrRegs_0x10_SocElement()` | SOC 参数 |
| `Sci_WrRegs_0x10_SystemElement()` | 系统参数 |
| `Sci_WrRegs_0x10_OtherElement()` | OtherElement 全部字段 |
| `Sci_WrRegs_0x10_FlashConnect()` | Flash 连接/进入 IAP |
| `Sci_WrRegs_0x10_SN_Version()` | 序列号/版本号 |

### 响应状态码

**源文件**: `Sci_Upper.h:93-103`

| 状态 | 值 | 含义 |
|------|-----|------|
| `RS485_ACK_POS` | 0x00 | 成功 |
| `RS485_ACK_NEG` | 0x01 | 失败（见错误类型） |
| `RS485_ERROR_ADDR_INVALID` | — | 地址无效 |
| `RS485_ERROR_CRC_ERROR` | — | CRC 错误 |
| `RS485_ERROR_DATA_INVALID` | — | 数据超出范围 |
| `RS485_ERROR_CMD_INVALID` | — | 命令无效 |
| `RS485_ERROR_RONLY_NO_W` | — | 只读区不可写 |
| `RS485_ERROR_WONLY_NO_R` | — | 只写区不可读 |
| `RS485_ERROR_NO_PERMISSION` | — | 权限不足 |

## CAN 协议 (飞道)

**源文件**: `Can_HDX.c/.h`, `CanFeidaoFrames.c/.h`

### 物理层

| 参数 | 值 |
|------|-----|
| 比特率 | 250 kbit/s |
| 帧格式 | 扩展帧 (29-bit ID) |
| 基地址 | `0x14F80200` |
| TX 队列深度 | 32 |
| 应用命令队列深度 | 4 |

### 周期性数据帧

**源文件**: `CanFeidaoFrames.c:28-36`

| 掩码位 | 帧 | 周期 | 数据内容 |
|--------|-----|------|---------|
| 0x0001 | 电压电流帧 | 1s | 总压 (u32 mV) + 电流 (u32 mA, 负=放电) |
| 0x0002 | SOC 帧 | 1s | SOC (0-100%) |
| 0x0004 | 容量帧 | 5s | 当前容量 / 满充容量 / 出厂容量 |
| 0x0008 | SOH 帧 | 5s | SOH (0-100%) |
| 0x0010 | 版本帧 | 5s | 硬件版本 / 软件版本 |
| 0x0020 | 状态帧 | 5s | MOS 状态 + 故障标志 |
| 0x0040 | 老化时间帧 | 5s | 工厂老化剩余时间 |

### CAN 应用指令

**源文件**: `Can_HDX.c:28-53`

指令帧 ID: `BaseID | (0x60 应用指令) | 通道`
响应帧 ID: `BaseID | (0x61 应用确认) | 通道`

| 子命令 ID | 命令 | 功能 |
|----------|------|------|
| 0x01 | GET_STATUS | 读取 BMS 运行状态 |
| 0x02 | ENTER_IAP | 请求进入 IAP 模式 |
| 0x03 | READ_REG | 读单个寄存器 |
| 0x04 | WRITE_PREP | 写准备 |
| 0x05 | WRITE_COMMIT | 写提交 |
| 0x06 | READ_BLOCK | 读连续块 (≤120 字) |
| 0x86 | READ_BLOCK_DATA | 读块数据响应 |
| 0x07 | AGING_START | 启动工厂老化 |
| 0x08 | AGING_STOP | 停止工厂老化 |
| 0x09 | AGING_RESET_TIME | 重置老化时间 |
| 0x0A | AGING_SET_HOURS | 设置老化时长 |

## 通信工具协议桥接

**源文件**: `firmware/comm_tool_f103ret6/source/app/ct_can_gateway.c`

通信工具充当 RS485 ↔ CAN 的协议桥接器：
1. 通过 UART 接收上位机指令
2. `ct_protocol` 解析 UART 帧
3. `ct_app` 处理帧，可能转换并转发到 CAN 总线
4. CAN 响应回传 UART

## I2C 协议 (AFE 通信)

**源文件**: `I2C_AFE1.c/.h`

### 不是硬件 I2C，是软件模拟 TWI

| 参数 | 值 |
|------|-----|
| 类型 | GPIO 位带操作（软件模拟） |
| SCL | PB8 |
| SDA | PB9 |
| AFE 从机地址 | 0x34 (7-bit) |
| 校验 | CRC8（查表法，多项式待确认） |
| 重试 | 失败重试 1 次，仍然失败则报告 ERROR_AFE1 |

### TWI 时序

```
Start → SlaveAddr+W → ACK → RegAddr → ACK → Data → CRC8 → ACK → Stop
```

读操作：
```
Start → SlaveAddr+W → ACK → RegAddr → ACK
ReStart → SlaveAddr+R → ACK → Data → CRC8 → NAK → Stop
```

### MTP 操作

- `MTPWrite(addr, len, buf)`: 写 AFE MTP 寄存器
- `MTPWriteROM(addr, len, buf)`: 写 AFE 配置 ROM (0x00-0x19)，40ms 重试延时
- `MTPRead(addr, len, buf)`: 读 AFE MTP 寄存器

> **性能**: 每次 AFE 数据更新 = 2 次 I2C 事务（状态 + 数据）= ~6ms @ 100kHz
