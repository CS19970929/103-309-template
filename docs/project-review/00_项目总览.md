# 00 — 项目总览

## 项目名称

**锂电池保护板 BMS（Battery Management System）固件**

## 项目定位

面向 10~16 串锂电池组的保护板固件系统，基于 STM32F103 系列 MCU，采用 SH367309 AFE 芯片进行电池单体监控。支持三元锂（TERNARYLI）和磷酸铁锂（LIFEPO）两种化学体系。

## 技术栈

| 层级 | 技术 |
|------|------|
| MCU | STM32F103Rx / STM32F103Cx (Cortex-M3, 72MHz) |
| AFE 芯片 | SH367309 (I2C 接口, 最大 16 串) |
| IDE | Keil MDK (uVision 5) |
| 标准库 | STM32F10x Standard Peripheral Library V3.5.0 |
| 通信协议 | RS485 (Modbus-like) + CAN (飞道私有协议) |
| 存储 | 内部 Flash (A/B 双槽位 + 日志型磨损均衡) |
| 低功耗 | STM32 STOP 模式 + RTC 闹钟唤醒 |

## 核心功能清单

1. **电池监控**: 单体电压（10~16 串）、总压、充放电电流、温度（AFE 3 路 + NTC 2 路 + MOS 1 路）
2. **三级保护**: 一级（警告）/ 二级（限功率）/ 三级（关断），涵盖 13 种故障类型
3. **SOC 估算**: 安时积分 + OCV 校准 + 满充校准 + 低尾校准 + 静置漂移修正
4. **RS485 通信**: Modbus-like 协议，支持校准系数、保护参数、SOC/系统配置的读写
5. **CAN 通信**: 飞道私有协议，周期性上报 + 应用指令处理（含工厂老化控制）
6. **低功耗休眠**: 三种模式（Normal / Hiccup / Deep），RTC 唤醒 + 多种外部唤醒源
7. **参数持久化**: Flash A/B 槽位磨损均衡，支持保护参数、AFE 校准、事件日志、SOC 快照
8. **固件升级**: SRAM 邮箱握手协议，CAN 总线 IAP，支持升级参数策略
9. **工厂老化**: 72 小时可配置老化测试，Flash + 备份寄存器双重持久化
10. **调试系统**: Keil 实时监控、中断追踪、性能剖析（Release 构建时完全移除）

## 关键架构决策

- **`main.h` 作为中央包含文件**: 所有模块通过 `main.h` 互相引用，避免复杂的 include 依赖
- **裸机调度**: 无 RTOS，`Runtime_RunOnce()` 在大循环中按固定顺序调用各模块任务
- **配置三层结构**: `Project_Config.h`（用户）→ `conf.h`（翻译层）→ `Project_BuildGuard.h`（编译检查）
- **Flash 存储无文件系统**: 直接操作物理地址，使用序列号 + CRC 保证数据完整性
- **AFE 即主保护**: SH367309 硬件执行最底层保护，MCU 软件执行补充保护和故障记录
- **I2C 软件模拟**: 不使用 STM32 硬件 I2C 外设，用 GPIO 位带操作实现 TWI 协议（有 CRC8 校验）

## 编码规范

- 源文件编码: **GBK**（中文注释和字符串）
- 数据类型: `UINT8` / `UINT16` / `UINT32` / `UINT64`（ST 标准库别名）
- 全局变量前缀: `g_`
- 结构体命名: 全大写 + 下划线（如 `SYSTEM_ERROR`）
- 枚举命名: 模块前缀 + 下划线（如 `RS485_CMD_E`）
- 位域模式: `union { UINTxx all; struct { ... } bits; }`
- 延时单位: 10ms（`DELAYB10MS_*` 宏族）
