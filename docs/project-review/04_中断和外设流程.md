### 中断优先级

**源文件**: `System_Init.c: InitNVIC()`

NVIC 优先级分组配置为 **2:2**（2 位抢占优先级 + 2 位子优先级）。

> **待确认**: 各中断通道的具体优先级数值需要查看 `InitNVIC()` 的完整代码。从 `stm32f10x_it.c` 的 Fault Handler 逻辑推断，HardFault/MemManage/BusFault/UsageFault 具有最高优先级。

## 故障中断流程

### HardFault 处理流程

```
HardFault_Handler()  [stm32f10x_it.c:95]
  ├── IrqDebug_SetPhase(FAULT)
  ├── IrqDebug_Count(HARDFAULT)
  ├── 读取 SCB->HFSR, CFSR, MMFAR, BFAR
  ├── 写入 BKP_DR16 (HardFault 原因码)
  ├── DisableAllIRQ()
  ├── 等待 100ms
  └── NVIC_SystemReset()
```

**故障原因码** (定义在 `FaultSnapshot.h`):
- `FAULT_REASON_HARD = 0x4846` (HardFault)
- `FAULT_REASON_MEM = 0x4D46` (MemManage)
- `FAULT_REASON_BUS = 0x4246` (BusFault)
- `FAULT_REASON_USAGE = 0x5546` (UsageFault)

### BusFault / MemManage / UsageFault 处理

所有三个处理器的处理逻辑一致：记录 IRQDBG → 设置 FAULT 阶段 → 复位。

> **风险**: 复位后，BKP_DR16 中保存的故障原因可被下一轮启动读取，但当前代码中未发现利用此信息的恢复逻辑。

## I2C 通信流程（AFE 数据读取）

```
App_AFEGet()  [DataDeal.c:1192]
  └── UpdateVoltageFromBqMaximo()  [I2C_AFE1.c:719]  ← 注意: 函数名含 "Bq" 是历史遗留
        ├── MTPRead(0x43, 5)   → Registers_AFE1 (BSTATUS1-3, BALANCEH/L)
        ├── MTPRead(0x4E, 46)  → SH367309_Read_AFE1 (Cell1-16, Temp1-3, PackV, Cur)
        └── CRC 校验 (...)
  └── DataLoad_CellVolt()      [DataDeal.c:198]
  └── DataLoad_Temperature()   [DataDeal.c:272]
  └── DataLoad_Current()       [DataDeal.c:840]
```

每次 AFE 数据读取包含 **两次 I2C 事务**：
1. 读状态寄存器 (BSTATUS1-3, BALANCEH/L) = 5 字节
2. 读测量数据 (16 路电压 + 3 路温度 + 总压 + 电流) = 46 字节
