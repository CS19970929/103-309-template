# SOC 可用容量比例

## 配置与对外行为

在 `103 + 309/Project/Source/SocEnhance.h` 设置
`SOC_USABLE_CAPACITY_PERCENT`，默认 `90U`，允许 1～100；0 或大于 100
编译报错。100 表示取消容量折减。这是编译期产品配置，未增加上位机参数、
寄存器或持久化字段。设置容量仍使用已有 `OtherElement.u16Soc_Ah`。

| 数据 | 计算口径 |
| --- | --- |
| 对外标称容量、满充容量 | 原设置容量，保持原 SOH 定义 |
| 对外剩余容量 | 设置容量 × 当前 SOC 百分比 |
| SOC 积分、内部剩余电量 | 设置容量 × 可用容量比例 |
| 充放电剩余时间 | 内部剩余/待充电量 ÷ 当前电流 |
| 循环次数 | 标称容量基准，保留累计 80% 计一次及零 SOC 不计数规则 |

例如设置 100 Ah、比例 90%，满电内部电量为 90 Ah。放出 45 Ah 后 SOC 为
50%，对外剩余容量显示 50 Ah，内部剩余可用电量为 45 Ah。以 10 A 继续
放电，估算 270 分钟。显示容量不代表在当前截止电压下还能实际释放的 Ah；
若外部设备自行用显示容量计算时间，其算法也必须知道这一口径。

时间计算不再使用旧 `CURRENT_K_CHG/DSG = 100/93` 折减，防止与 90%
重复折减。本次提交不修改已有本地配置文件。
100% 配置取消容量折减，也不会恢复旧时间估算的额外 93% 折减。

## 状态所有者与调用链

`SocEnhance.c` 内部状态保留 `u32CapFactory`、`u32CapFull` 的标称容量
口径，新增 `u32CapUsable`。内部容量和剩余电量单位为 0.1 As，电流为 0.1 A。
`u32CapNow` 使用可用容量基准，`i32SocChangeScaled` 保存 0.1 As × 100 的积分
有符号余数，不逐秒舍弃小数；充放电换向先抵消反方向余数，避免重复累计
不足 1% 的电量变化，也避免小容量/低比例时 SOC 与电量脱离。
协议容量仍为 0.01 Ah。

- 初始化和容量参数刷新计算可用满容量。
- 一秒充放电积分使用可用容量作为百分比分母，对电量和 SOC 做饱和处理；
  乘法、除法换算使用必要的 64 位中间值，避免小容量/大电流造成 SOC 回绕。
- `SOC_RebuildRemainingCapacity()` 在恢复、手动设置 SOC、OCV 校正和端点
  校正后，按当前百分比重建内部电量并清除旧积分余数。OCV 百分比不再乘比例。
- `SOC_Result_Pass()` 和启动上报将剩余容量映射到设置容量。
- `DataLoad_Current()` 取得当前电流后，通过 `SOC_GetRemainingMinutes()`
  读取内部可用电量估算时间，不从显示容量反推。`time_real` 同步使用此口径。
  主循环仍按原顺序运行，时间使用最近一次 SOC 状态，无新增 ISR 访问。

时间以整数分钟向下取整。未初始化、容量为零或查询电流为零时返回
`0xFFFF`；超长有效时间饱和为 `0xFFFE`，避免与无效值混淆。充电时放电时间
无效，放电时充电时间无效；无电流时保持既有 SOC=0/100 的端点时间表示。
容量上报超出原 16 位字段范围时饱和，正常支持的容量范围内单位和格式不变。

循环累计改为直接积分放电电量，以标称容量计算整数百分比。
`u32CycleCapChangeScaled` 保存未满 1% 的 RAM 余数，避免可用容量比例变化
影响循环计数速度。已存的累计放电百分比仍为原标称容量百分比。
容量刷新沿用原有显式循环次数设置/累计清零行为。

## 兼容与限制

保护电压、3050 mV 零电量校正及其时序、按键、OCV 表、通信字段、CAN ID、
单位、字节序、Flash/EEPROM 布局和休眠保存入口均不改变。
保存仍使用原有 SOC、累计放电百分比、循环次数三个字，读回按原比例解释。
新增的不足 1% 循环余数只保存在 RAM，重启会丢失这部分小于标称容量 1% 的
累计量，不扩展旧记录。原有保存机制和掉电一致性边界不变。

当前工作树另有未提交的 `conf.h` 修改，将 `EEPROM_VALUE_BEGIN_FLAG` 从
`0x0701` 改成 `0x4701`。`InitData_E2prom()` 在标识不匹配时会走原有首次
初始化路径；因此旧标识设备的参数初始化风险来自该本地配置修改。
本次 SOC 提交不包含此改动，也不改动启动初始化规则。旧记录恢复兼容的前提
是设备通过既有 EEPROM 标识检查。

升级后保留已存 SOC 百分比，按新的可用容量重建电量；不自动将旧 SOC 除以
0.9，不清空历史参数。首次升级的绝对剩余电量仍需要满充/放空校正。
90% 是工程配置，不能仅凭 3000/3050 mV 推导其准确性；必须结合实测容量
调整。低压保护可以提前终止放电，容量折算不能保证时间预测覆盖单体差异、
低温或负载压降。充电时间仍按当前电流外推，不能精确预测恒压尾段。
