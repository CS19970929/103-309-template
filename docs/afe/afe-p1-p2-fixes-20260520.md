## 关键修复点

1. AFE 串数入口收敛

   新增 `AFE3520_NormalizeSeriesNum()` 和 `AFE3520_SyncSeriesNum()`，把运行串数限制在 4 到 20 串范围内。启动、上位机写系统参数、单体电压读取和最大最小值统计都走同一入口，避免非法 `SeriesNum` 导致数组越界、未填充单体参与统计或 EEPROM 参数与运行变量不同步。

2. 采样电阻系数保护

   新增 `AFE3520_UpdateSenseResScaleSafe()`，集中处理 `OtherElement.u16Sys_CS_Res` 和 `OtherElement.u16Sys_CS_Res_Num` 为 0 的情况，并回落到编译期默认 `CS_Res` / `CS_Res_Num`。这覆盖启动、EEPROM 恢复、上位机写参数、AFE 数据恢复、短路阈值映射和 MCU ADC 电流换算路径，避免除零或换算比例变成 0。

3. CADC 电流换算统一

   新增 `AFE3520_CadcRawToCurrentMa()`，充电和放电都先取原始码值幅度，再用 `uint64_t` 完成乘法后除以 `29127`。这修正了旧放电公式里先除后乘带来的精度损失，也避免大电流或大采样电阻系数时 32 位中间值溢出。

4. NTC 分压换算防护

   `I2C_AFE1.c` 中五路温度 ADC 改为 `AFE3520_TempCodeToNtcX100()`。当 ADC 码值大于等于 32768 时返回饱和值 65535，不再执行 `32768 - adc_code` 的除零或下溢。

5. B+ / C+ 电压换算表达式收敛

   `VTOP` 和 `VCHGR` 换算改为 `raw * 125 >> 5`。功能上等价于原有 `raw * 5 / 32 * 25` 的意图，但乘法和移位顺序明确，避免维护时误读为 `raw * 5 >> (5 * 25)` 或再次引入优先级问题。

6. AFE 寄存器地址修正

   `sh36735_regs.h` 中只读状态寄存器区修正为：

   | 宏 | 地址 |
   | --- | --- |
   | `SH_REG_FLAG1` | `0x58` |
   | `SH_REG_FLAG2` | `0x59` |
   | `SH_REG_FLAG3` | `0x5A` |
   | `SH_REG_BSTATUS1` | `0x5B` |
   | `SH_REG_BSTATUS2` | `0x5C` |

   该修正与 PDF 和主工程实际 `SH36735_reg.h` 的常读结构保持一致。

7. 参数工具函数修复

   `sh_encode_ovh_ovt()` 现在按 PDF 把 `OVT[2:0]` 和 `OV[9:8]` 写入 `0x49`，把 `OV[7:0]` 写入 `0x4A`，不再把两个寄存器颠倒。`sh_decode_occ_occt()` 改用整数四舍五入公式计算 OCC mV，并补齐缺失的 `return out;`。
