# SH367309 启动门控与自动均衡

## CTLC 启动顺序

1. `conf.c/InitIO()` 在启动时、GPIO 输出模式启用之前将 PB14（`PIN_AFE1_CTL`）锁存置低。已完成校准的 STOP 唤醒保留原输出电平，避免新增关断脉冲。
2. `InitAFE1()` 将 CTLC 保持低电平后初始化 AFE，不再直接开启 CTLC。AFE 配置、复位及公共驱动使能入口在校准未结束时只开启 CADC，保持 CHGMOS、DSGMOS、PCHMOS 关闭。
3. `BmsCurrent_BootZeroCalibrate()` 保留原有两次新 CADC 采样、300 ms 间隔、控制寄存器读回、前后 FET 状态检查和偏移/稳定性检查。采样窗口内状态一直为 `BOOT_CURRENT_ZERO_NOT_RUN`。
4. 成功或失败回退后状态退出 `NOT_RUN`。失败按用户选择继续使用零点 0、500 mA 死区；不会永久锁 MOS。
5. `Drivers_External_Ctrl()` 是 CTLC 唯一拉高入口。校准结束前直接保持低电平并返回；结束后仍遵守 MOS 总开关和强制关闭条件。启动初始化不提前拉高，进入正常控制后才允许打开。
6. 运行时 AFE 重初始化先关闭 CTLC；已结束的校准状态和 RAM 零点保留，下一次正常控制恢复权限，不重复校准。STOP 唤醒也保留当前零点。

首次初始化旧的 16 次偏移采集、EEPROM 旧偏移读取/写入、全局偏移变量及专用地址宏已删除。历史存储字节保留，其他参数布局及全范围充放电 K/B 校准保持不变。

## AFE 配置

依据中颖 SH367309 V1.1 原始规格书第 31、32、38、55 页：

| 地址/字段 | 配置 | 作用 |
| --- | --- | --- |
| `SCONF1(0x00).BAL`，bit 4 | `0` | AFE 内部逻辑决定均衡开启，内部安排奇偶时序 |
| `SCONF2(0x01).CTLC[1:0]`，bit 3:2 | `3`，掩码 `0x0C` | CTL 输入低电平时关闭充电、放电和预充 MOS |
| `BALV(0x08)` | `0xAA`（170） | 170 × 20 mV = **3400 mV** |

`SH367309_Func.h` 的默认模板和 `Refresh_Parameters()` 的实际配置路径均设置以上值。保留的工厂参数配置入口使用同样配置。只修改这些位和阈值，不覆盖 SCONF1/2 的其他保护配置。

继续通过既有 AFE EEPROM 配置流程比较差异、按变化字节写入、复位生效。没有差异时不擦写；写失败或整体读回不一致时返回失败，保留重试标志。TR 读取失败时停止本次配置，避免用未初始化模板写入保护参数。

旧 MCU 软件均衡状态机、逐串筛选、压差窗口、静置等待、奇偶开关计时、均衡引起的 MOS 开关状态机，以及对 BALANCEH/L 的软件写入已删除。

自动均衡按 AFE 规格执行：未发生温度保护、未发生二次过充保护，单体电压超过 VBAL 并满足芯片延时后开启；低于阈值或发生上述保护时停止。软件不再附加静置、电流和压差条件。现有二次过充保护使能配置未在本次修改。

## 对外兼容与状态报告

`OtherElement` 中的均衡开启电压、压差窗口、默认显示值和协议/存储位置均不修改。上述旧软件策略字段及均衡开关字段继续保留读写兼容，但不参与当前 AFE 自动均衡决策；实际阈值由 `VAL_BAL_OPEN=3400` 配置。修改对外显示值不会修改 AFE 的 3400 mV 阈值。

`Cell_balance.c` 只保留 `CellBalance_UpdateReport()`，把读回的 AFE BALANCEH/L 位图按既有串位映射发布到 `u16BalanceFlag1`，第二 AFE 的位图保持 0；读回失败时不伪造新状态。沿用既有 `SeriesSelect_AFE1` 表，不改变串位定义。

普通 RTC 休眠检查不再依赖已删除的软件均衡状态枚举：重新读取均衡寄存器，读取失败或存在已报告均衡位时禁止本次普通休眠。其他电流、加热及 MOS/充电器检查保留。寄存器位图是软件报告依据，自动模式下的寄存器更新及实际均衡波形仍需实板核对，不能把位图当作模拟开关测量结果。

- ARMCC 5.06 update 7，`Target 1` 全量编译链接：0 错误、35 条既有警告；关闭所有后处理和 BIN/HEX 转换，仅验证目标编译与链接。
- 所有测试/编译中间产物在用户 `LOCALAPPDATA\CodexTemp\103-309-template` 下，未烧录、未操作硬件。

实板应检查冷上电及 MCU 复位时 CTL、CHG、DSG 的完整波形，确认校准窗口内无开启脉冲，并读回 `SCONF1.BAL`、`SCONF2.CTLC`、`BALV`；在阈值上下核对自动均衡、温度保护及睡眠行为。MCU 接管前的 CTL 电平取决于硬件上下拉和 AFE 已存配置；首次从旧 `CTLC=0` 配置升级时，仅靠软件不能保证 MCU 执行前的 MOS 状态。
