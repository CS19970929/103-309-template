## 1. 归档原则

1. 只有用户确认后，才移动旧文档到 `docs/archive/old_docs/`。
2. 归档不是删除，归档后仍需保留索引和来源路径。
3. 旧文档若与源码冲突，归档索引中必须标明冲突原因。
4. 权威文档始终以 `docs/README.md` 列出的 CURRENT 文档为准。

## 2. 当前建议归档主题

- 旧低功耗阶段设计和迁移计划。

- 旧 SOC 简化/修复阶段记录。
- 旧 LedBar 阶段记录。
- 历史 review 和重构计划。
