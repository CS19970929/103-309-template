Comm Tool 与 BMS App 审阅、日志和运行架构

日期：2026-05-25；范围：PC 上位机、comm tool F103RET6 App、BMS App 通信服务、Debug/Release 日志策略。

结论

已修复

BMS App 的 EasyLogger 现在只在 Debug profile 打开，Release profile 由 Project_BuildGuard.h 硬性禁止。

已新增

comm tool 新增 Debug 环形结构化日志，PC 通过 0x42 DEBUG_LOG 或 tools/comm_tool_host.py debug-log 读取，不把文本日志混入二进制串口协议。

使用建议

串口可以用于 BMS Debug 串口日志，但不建议在 comm tool 协议 UART 上直接 printf。更好的方式是结构化诊断命令、CAN 诊断计数、上位机 CSV 和 ST-Link/Keil Watch。

审阅发现

级别位置发现处理结果
Bug AppInit.c 原逻辑如果打开 ELOG_OUTPUT_ENABLE，会在 AppInit_InitSci() 后再次调用 InitUSART_CommonUpper()，并可能重复初始化日志。 已改为只初始化 SCI 一次，随后在 Debug 日志开关下调用 elogInit()。
Bug 风险 comm tool UART comm tool 的 UART 是二进制帧协议。如果直接输出 ASCII 日志，上位机会把日志字节当成协议流，造成 CRC 错误、超时或错帧。 已新增内存环形日志和 DEBUG_LOG 命令，避免污染协议 UART。
可靠性风险 CtBoard_CanSend() / CAN 升级链路 CAN 发送失败、无邮箱、超时以前只能看 CAN_DIAG 当前快照，缺少按时间排序的过程日志。 已把 CAN 发送失败、超时、升级阶段、升级错误写入 Debug 环形日志。
配置风险 BMS Release Release 必须禁止串口日志、ELOG_OUTPUT_ENABLE、printf 相关调试输出，否则会影响通信和体积。 已增加 PROJECT_CFG_DEBUG_SERIAL_LOG_ENABLE 和 Release 编译保护。
建议 comm tool Keil 工程 当前正式工程目标仍是 COMM_TOOL_Release。Debug 日志可通过定义 CT_BUILD_PROFILE=1 打开。 建议后续单独增加 COMM_TOOL_Debug Target，避免手动改 Define。

日志策略

对象ReleaseDebug读取方式说明
comm tool 关闭，CT_DEBUG_LOG_ENABLE=0 打开，CT_BUILD_PROFILE=1 时启用 tools/comm_tool_host.py debug-log --port COMx --baud 115200 结构化环形日志，不占用额外串口，不破坏二进制协议。
BMS App 关闭，编译保护禁止 PROJECT_CFG_DEBUG_SERIAL_LOG_ENABLE=1 时启用 EasyLogger 调试串口终端或 USB-UART 只适合台架调试；不要和上位机协议通信同时抢同一个串口。
现场问题采集 允许 允许 CAN_DIAG、BMS 事件日志、上位机 CSV、ST-Link 快照 生产和现场优先使用结构化数据，不依赖 printf。

comm tool 运行架构

PC UI / comm_tool_host.py 通过 UART 发送 55 AA 二进制帧。
CtProtocol_Feed() 完成帧同步、长度检查和 CRC16 校验。
CtApp_HandleFrame() 分发 GET_INFO、SET_CAN、BMS_READ、FW_*、UPGRADE、CAN_DIAG、DEBUG_LOG。
CtCanGateway 把 BMS 寄存器读写、老化控制、进入 IAP 转成 CAN App 服务帧。
CtUpgrade_Task() 使用缓存区固件，按 HELLO / START / DATA / COMMIT / END 状态机完成 CAN-IAP 升级。

BMS App 运行流程

main() 调用 AppInit_Boot()，完成时钟、IO、SCI、Flash、AFE、CAN、ADC、SOC、Timer、RTC 初始化。
主循环只调用 Runtime_RunOnce()，避免初始化逻辑散落在主循环。
Runtime_RunFrontTasks() 处理任务标志、工厂老化、灯条、AFE 数据。
Runtime_RunIoAndPowerTasks() 处理上位机通信、模拟校准、低功耗、CAN 服务。
Runtime_RunBackgroundTasks() 处理 Flash 更新、事件日志、生产 ID 和看门狗喂狗。

后续建议

  • 给 comm tool Keil 工程补一个正式 COMM_TOOL_Debug Target，Define 固定为 CT_BUILD_PROFILE=1,_DEBUG_。
  • 上位机 UI 可增加“读取 Debug Log”按钮，内部复用 0x42 DEBUG_LOG。
  • BMS App 如果需要现场长期日志，优先扩展 Flash 事件日志或只读诊断寄存器，不建议打开串口文本日志。
  • 升级失败定位优先看：debug-log、can-diag、UPGRADE_STATUS.last_error、BMS 事件日志。
