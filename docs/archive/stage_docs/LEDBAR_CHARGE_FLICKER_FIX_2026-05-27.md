# LedBar 充电时闪烁与常亮修正

状态：部分验证

日期：2026-05-27

## 问题

接入 5V 充电时，数码管有明显闪烁感；此前尝试调整扫描和图标状态后，出现了充电时数码管常亮不灭，不符合“单击/唤醒后显示一段时间，到时熄灭”的需求。

## 原因判断

`GPIO_SW / PA9` 是按键输入。充电时该输入如果受干扰或被判断为持续按下，旧逻辑会让 `key_last_pressed` 一直保持显示请求，并且显示窗口倒计时不再递减，导致数码管常亮。显示窗口必须独立于按键当前电平倒计时。

## 修改

- 撤回扫描周期和充电/输出图标状态去抖改动，避免引入与需求无关的显示行为变化。
- `GPIO_SW / PA9` 改为 30ms 去抖后的按下沿触发 SOC 显示窗口。
- `LedBar_IsDisplayRequested()` 只由 `soc_display_10ms` 窗口决定，不再因为按键当前电平持续为按下而常亮。
- `soc_display_10ms` 在 10ms tick 中持续递减，即使按键输入保持低电平也会按窗口时间熄灭。

## 验证

1. 正常模式短按显示 SOC，确认显示窗口结束后熄灭。
2. 接入 5V 充电，不按键时确认数码管不会常亮。
3. 充电时短按 `GPIO_SW / PA9`，确认显示 SOC，窗口结束后熄灭。
4. 充电时观察是否仍有闪烁；若仍闪烁，下一步应上板抓 `GPIO_SW / PA9` 和 LedBar route 波形，而不是继续扩大显示策略。
