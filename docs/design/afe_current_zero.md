# AFE 电流零点与换算

## 当前规则

- MCU 每次复位启动时只执行一次 AFE 电流零点校准。
- 冷启动使用 `800 ms / 32 次 / 丢弃 6 次 / 25 ms` 参数。
- 深度休眠复位后的启动使用 `120 ms / 16 次 / 丢弃 2 次 / 20 ms` 参数。
- 校准要求连续 4 个有效样本，相邻原始码变化不超过 8，样本对应电流不超过 1 A。
- 校准超时时，有有效样本就使用当前连续样本的平均值；没有有效样本时零点保持 0。
- 普通 STOP/HICCUP 唤醒以及运行中的 AFE 通信恢复不重新校准。
- 运行过程中零点固定，不进行自动学习或漂移修正。

## 电流换算

运行时电流路径固定为：

1. 将 AFE CADC 原始码转换为有符号值。
2. 减去开机得到的 `zeroOffsetRaw`。
3. 按现有采样电阻参数换算为 mA。
4. 小于 200 mA 的输出按 0 处理。
5. 正值报告为充电电流，负值绝对值报告为放电电流，协议单位保持 `A × 10`。

`AfeCurrent_GetSeq()`继续作为 SOC 判断 200 ms 新电流样本的依据。CAN、Modbus 字段、方向和单位不变。

## 维护边界

- 不要在 `DataLoad_Current()`中重新引入运行时零点学习。
- 若开机校准失败，运行中不会自动恢复零点，只能等待下一次复位重新校准。
- 电流 K/B 修正当前未启用；校准寄存器布局仍为协议兼容保留，不属于本次零点逻辑。
- AFE CADC 使能、CTLC 和 MOS 初始化顺序涉及硬件时序，修改时必须单独验证。
