# LED/按键/上下电需求整理

日期：2026-05-27

## 硬件定义

- L1 为双色复用灯：绿灯参与电量显示，黄灯表示低 SOC 或过放报警。
- L2-L5 为单色电量灯。
- SOC_KEY 使用 PA9，按下为低电平。
- 充电唤醒信号使用 PA0，同时运行态也参考实际充电电流 `u16Ichg`。

## 休眠态开机

- 休眠后按一下 SOC_KEY，必须立即显示备份域中保存的 SOC，不等待 AFE、ADC、SOC、EEPROM、CAN 初始化。
- 短按显示期间不上电，不释放 CHG/DSG MOS。
- 8 秒内没有继续长按，所有灯熄灭，重新进入 STOP 休眠。
- 8 秒内持续长按满 3 秒，从 L1 到 L5 依次点亮，动画完成后进入完整开机流程。
- 休眠状态检测到充电，立即唤醒并进入完整开机流程，不需要长按 3 秒。

## 工作状态

- 20 <= SOC < 40：L1-L2 绿灯常亮。
- 40 <= SOC < 60：L1-L3 绿灯常亮。
- 60 <= SOC < 80：L1-L4 绿灯常亮。
- 80 <= SOC <= 100：L1-L5 绿灯常亮。
- SOC < 20、单体欠压、总压欠压或 SOC Low 时，L1 黄灯闪烁，其余电量灯熄灭。

## 充电状态

- 充电时 L1 使用绿灯，不显示黄灯报警。
- 已达到的档位常亮。
- 下一档闪烁，不做多灯跑马。
- 充电档位按截图文字采用严格大于：SOC > 20 点亮 L1，SOC > 40 点亮 L2，SOC > 60 点亮 L3，SOC > 80 点亮 L4，SOC >= 100 点亮 L5。

## 关机状态

- 工作状态按一下 SOC_KEY，立即进入关机确认。
- 关机确认阶段 L1 熄灭，L2-L5 闪烁，不关闭 MOS。
- 8 秒内没有继续长按，恢复工作灯显，放电保持。
- 8 秒内持续长按满 3 秒，从 L5 开始依次熄灭 L4、L3、L2，最后全灭。
- 关机动作在熄灯动画结束后执行：CHG/DSG 都关闭，并进入 AFE_Sleep。
