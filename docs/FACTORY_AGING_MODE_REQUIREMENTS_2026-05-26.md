# 老化模式运行定义

## 固件行为

- 老化模式运行态定义为：状态为运行，且剩余老化时间未到。
- 上位机执行“修改老化时间”时，固件必须同步重置已运行时间，并立即进入老化运行态。
- 上位机执行“重置老化时间”时，固件必须同步清零已运行时间，并立即进入老化运行态。
- 上位机执行“开启老化模式”时，固件进入老化运行态。
- 上位机执行“关闭老化模式”时，固件提前结束本轮老化时间，进入完成态并保存完成态；再次上电仍保持完成，直到上位机重新重置或修改老化时间。
- 老化时间到达后，固件进入完成态，并保存完成态。

## MOS 控制规则

- 老化运行态下统一调用 `enter_fac_mode(true)` 应用 MOS。
- 无 `GPIO_CHG_IN` 5V 充电识别信号时，老化运行态自动打开充电 MOS 和放电 MOS，不再依赖 5V 信号进入老化。
- 有 `GPIO_CHG_IN` 5V 充电识别信号时，老化运行态打开充电 MOS，关闭放电 MOS。
- 老化任务循环会检测 5V 状态变化，只在 5V/非 5V 模式切换时重新应用 MOS，避免周期性重复写 AFE。

## 上位机显示要求

- 修改老化时间成功后，上位机读取到的状态应为“运行”，剩余时间从新设置的小时数开始计算。
- 关闭老化模式后，上位机读取到的状态应为“完成”，剩余时间为 0。
- 老化时间到达后，上位机读取到的状态应为“完成”，剩余时间为 0。
