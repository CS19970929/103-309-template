# 03 接线映射填写说明

## 1. 核心思想

每个发光点都抽象成：

- 属于哪个位选
- 由哪两个 Charlie 线驱动
- 电流方向是什么

例如：

```c
[DISP_LED_TENS_A] = {1, 0, 1, 1}
```

表示：

- 这个 LED 属于 `74HC595 Q1` 选通的那一组
- `CHARLIE_PIN_0` 为阳极
- `CHARLIE_PIN_1` 为阴极
- `valid = 1`

---

## 2. 如何测出映射关系

推荐一个最稳的方法：

### 步骤1：固定某一位选

让 74HC595 只打开某一位，例如十分位。

### 步骤2：手工尝试 5 根线任意两两组合

5 根线可以形成：

- `5 * 4 = 20` 个有方向的组合

每试一次：

- 一根输出高
- 一根输出低
- 其他高阻

记录哪个段亮。

### 步骤3：整理成表

例如记录出：

- 十分位 a = Q1 + P0->P1
- 十分位 b = Q1 + P0->P2
- ...

最后填入 `display_hw_map.c`

---

## 3. 注意事项

### 3.1 同一对线反向是两个不同通路

`P0 -> P1` 和 `P1 -> P0` 是不同的。

### 3.2 一定要其他引脚高阻

否则测试结果可能是假象。

### 3.3 位选不要混淆

十分位和个位即使段名都叫 `a`，也可能是不同位选。

---

## 4. 建议你先做的事

先不要急着整套跑：

1. 写一个“单点亮灯测试函数”
2. 一个个把映射表测出来
3. 映射表确认后再接入扫描框架

这是最省时间的方式。
