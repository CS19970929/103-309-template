# 02 移植说明

## 1. 需要移植的接口

### 1.1 74HC595 底层

在 `display_74hc595.c` 中实现：

- `disp595_hw_set_data()`
- `disp595_hw_set_clk()`
- `disp595_hw_set_latch()`
- `disp595_hw_delay_small()`

---

### 1.2 Charlie GPIO 底层

在 `display_charlie.c` 中实现：

- `charlie_hw_pin_mode()`
- `charlie_hw_pin_write()`

其中高阻模式一般做法：

- GPIO 配成输入浮空
- 或输入上拉/下拉（看你的硬件）
- 原则是不能主动驱动总线

---

## 2. 推荐接入方式

### 方案A：1ms定时器中断调用

优点：

- 亮度稳定
- 刷新固定
- 不依赖主循环负载

### 方案B：主循环节拍调用

要求：

- 主循环必须足够快
- 不能长时间阻塞

---

## 3. STM32 标准库移植提示

### 3.1 74HC595 GPIO 输出

你可直接使用：

- `GPIO_SetBits()`
- `GPIO_ResetBits()`

### 3.2 Charlie 高阻实现

常见做法：

- 输出时：`GPIO_Mode_Out_PP`
- 高阻时：改成 `GPIO_Mode_IN_FLOATING`

---

## 4. 初始化顺序建议

1. 先初始化所有 GPIO
2. 初始化 `74HC595`
3. 初始化显示模块 `display_init()`
4. 启动定时扫描

---

## 5. 常见问题

### 5.1 串亮/鬼影

原因通常是：

- 未先关闭所有输出
- 非目标线没有切高阻
- 位选切换与 Charlie 切换顺序不合理

### 5.2 亮度低

处理方法：

- 提高扫描频率
- 缩短无效间隔
- 检查限流电阻
- 检查 74HC595 是否适合直接带载

### 5.3 某段不亮

优先检查：

- 映射表
- 阳极/阴极方向是否写反
- 位选 bit 是否填错
