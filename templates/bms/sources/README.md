# 模板源码池说明

`sources/` 中的目录不是同等地位的应用层模板。

- `fd_103_309` 当前仍在仓库主工程目录 `103 + 309/Project/Source` 中维护，是通用模板应用层基线。
- `a002_f030_bq76940/` 是旧项目导入后的 port 参考源，只用于提取 `STM32F030`、`BQ76940`、Keil/scatter、Flash 地址和硬件资源信息。

后续项目配置生成器必须从当前项目应用层基线生成业务逻辑，再按 profile 替换 MCU port、AFE port 和配置头。禁止直接把 A002 旧应用层复制成新项目主线。
