# 公共上位机串口协议

## 相关文件

## 模块职责

`Sci_Upper` 是默认启用的上位机通信协议模块，用于状态读取、参数读写、校准、事件记录读取、生产信息读写和升级入口。

## 硬件资源

| 通道 | GPIO | 波特率 | 格式 |
| --- | --- | --- | --- |
| USART1 | PA9 TX / PA10 RX | 19200 | 8N1 |
| USART2 | PA2 TX / PA3 RX | 19200 | 8N1 |

`_COMMOM_UPPER_SCI1` 与 `_COMMOM_UPPER_SCI2` 默认同时启用。

## 协议类型

协议整体类似 Modbus RTU，主要命令包括：

| 命令 | 说明 |
| --- | --- |
| `0x03` | 读取寄存器/数据。 |
| `0x06` | 写单个寄存器/参数。 |
| `0x10` | 写多个寄存器/参数。 |

CRC 使用 `CRC16RTU`。

## 地址空间概览

| 地址段 | 内容 |
| --- | --- |
| `0xD000` | 运行状态与只读数据。 |
| `0xD100` | 扩展运行状态。 |
| `0xC000` | LCD/显示相关数据。 |
| `0xC008` | 事件记录读取。 |
| `0xFFF0` | 序列号。 |
| `0xFFF1` | 硬件版本。 |
| `0xFFF2` | 软件版本。 |
| `0xFFFD` | Flash 升级连接/标志。 |
| 保护参数区 | 保护阈值读写。 |
| 校准参数区 | 电压、电流、温度 K/B 校准。 |
| 其他参数区 | SOC、功能、系统扩展参数。 |

## 中断与接收

USART 中断只负责接收字节和更新通信状态，完整帧解析在主循环 `App_Sci()` 中执行。接收到数据会更新外部通信计数，供低功耗模块判断系统是否空闲。

## 与内部 Flash 存储的关系

上位机写入参数后，不应直接在协议路径长时间写 Flash，而是设置对应写入标志，由 `Storage_Task()` 分时保存。

## 维护建议

- 新增对外数据时应明确地址、长度、读写权限和内部 Flash 持久化策略。
- 修改结构体字段顺序可能破坏上位机兼容，应优先新增地址而不是重排旧地址。
- 协议异常回复应保持一致，避免上位机无法区分地址错误、长度错误和写保护状态。
