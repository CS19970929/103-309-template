# 公共工具函数

## 相关文件

- [PubFunc.c](../../Code/Source/PubFunc.c)
- [PubFunc.h](../../Code/Include/PubFunc.h)

## 模块职责

`PubFunc` 提供跨模块复用的基础算法和工具函数，避免通信、保护、SOC、校准等模块重复实现底层逻辑。

## 主要能力

| 能力 | 说明 |
| --- | --- |
| `CRC16RTU` | 上位机协议帧校验。 |
| `CRC8` | AFE 寄存器访问校验。 |
| 查表插值 | 温度、SOC、OCV 等曲线计算。 |
| `App_PubOPUPChk()` | 保护触发/恢复的滞回和滤波判断。 |
| 温度断线判断 | 辅助保护模块判断温度传感器异常。 |
| 奇偶/校验辅助 | 通信或数据处理辅助。 |

## `App_PubOPUPChk()` 价值

保护逻辑中大量使用该类公共判断函数。它将以下行为统一：

- 触发阈值判断。
- 恢复阈值判断。
- 触发滤波计数。
- 恢复滤波计数。
- 当前状态保持。

这样可以避免每个保护项手写一套类似但细节不同的状态机。

## 维护建议

- 新增保护判断优先复用公共滞回/滤波函数。
- 修改 CRC 或插值函数会影响多个模块，应先确认调用方范围。
- 公共函数应保持无硬件副作用，不直接访问 GPIO、EEPROM 或 AFE。
