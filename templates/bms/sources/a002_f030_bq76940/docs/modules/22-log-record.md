# 事件日志记录

## 相关文件

- [LogRecord.c](../../Code/Source/LogRecord.c)
- [LogRecord.h](../../Code/Include/LogRecord.h)
- [EEPROM.c](../../Code/Source/EEPROM.c)

## 模块职责

`LogRecord` 负责将系统关键事件压缩为事件记录，保存到内部 Flash 环形记录区，并向上位机提供读取和清空能力。

## 记录区域

事件记录保存在内部 Flash 逻辑地址区：

| 地址 | 内容 |
| --- | --- |
| `1000` 至 `1198` | 事件记录区。 |
| `1200` | 当前记录指针。 |

记录容量约 100 条。

## 典型事件

| 类型 | 说明 |
| --- | --- |
| 启动事件 | 系统上电或复位。 |
| 睡眠事件 | 进入/退出睡眠。 |
| 保护事件 | OV、UV、OCP、OTP、UTP 等。 |
| AFE 事件 | AFE 通信异常或内部状态异常。 |
| 存储事件 | 内部 Flash 存储异常或参数写入。 |
| 均衡事件 | 均衡开启/关闭。 |
| 加热/冷却事件 | 条件功能事件。 |

## 主调度

`App_LogRecord()` 通常按 1s 节拍执行，根据当前系统状态和事件标志决定是否写入新记录。清空事件记录也通过分时方式处理，避免长时间阻塞。

## 通信接口

`Sci_Upper` 可通过事件记录地址段读取历史事件，也可以触发事件记录清空。

## 维护建议

- 新增保护或关键状态时，应同步定义事件码和记录条件。
- 事件记录要避免高频重复写入，建议保留状态变化触发或最小间隔。
- 内部 Flash 记录区容量有限，新增字段前要评估单条记录长度与兼容性。
