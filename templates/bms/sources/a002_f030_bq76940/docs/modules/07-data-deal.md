## 模块职责

`DataDeal` 是运行数据汇总中心，负责将 AFE、ADC、校准参数和电芯映射关系转换为业务可用的标准数据结构。

核心输出是 `g_stCellInfoReport`，它被通信、保护、SOC、均衡、日志和生产测试功能共同使用。

## 主要输入

| 输入 | 来源 | 说明 |
| --- | --- | --- |
| 电芯电压原始值 | `BQ769x0` | 通过 AFE I2C 分段读取。 |
| Pack 电压 | `BQ769x0` | AFE 采样与换算。 |
| CC 电流 | `BQ769x0` | 经 K/B 校准后输出。 |
| AFE 温度 | `BQ769x0` | 内部/外部温度路径。 |
| 外部温度 | `ADC` | PA4、PA5、PB0。 |
| 校准参数 | 内部 Flash 参数区 | 电压、电流、温度 K/B 参数。 |
| 串数映射 | `SeriesSelect_AFE1` | 4 至 16 串逻辑到 AFE 通道映射。 |

## 主调度

`App_AFEGet()` 在主循环中执行，通常以 50ms 级别刷新。执行前会检查：

- 系统启动门控。
- 内部 Flash 参数区是否处于写入关键阶段。
- AFE 启动故障计数是否允许采样。

## 电芯映射

`SeriesSelect_AFE1[16][16]` 描述不同串数下逻辑电芯与 AFE 采样通道的关系。未使用的电芯位置通常填充为 `61001`，用于上层区分无效电芯。

维护串数配置时必须同步检查：

- `SNum`
- `SeriesSelect_AFE1`
- 均衡映射
- 通信协议中电芯数量
- 保护阈值数组长度

## 输出数据

| 数据 | 说明 |
| --- | --- |
| 单体电压 | 每串电芯电压。 |
| 最大/最小单体电压 | 保护、均衡和 SOC 计算使用。 |
| 压差 | 均衡和故障判断使用。 |
| Pack 总压 | 通信和保护使用。 |
| 电流 | 充放电判断、SOC 积分、保护判断使用。 |
| 温度 | 充放电温度保护、MOS 温度保护使用。 |
| SOC 元素 | 由 SOC 模块写入，同一 report 对外输出。 |

## AFE 监控辅助

`MonitorAFE()` 负责统计 AFE I2C 异常：

- 短期异常会增加错误计数。
- 达到一定次数后尝试唤醒或重新初始化 AFE。
- 超过严重阈值后设置系统错误。

## 维护建议

- 新增采样量时优先放入统一 report，再由通信、保护或日志读取，避免多个模块重复访问硬件。
- 电流、电压校准参数属于跨模块关键数据，修改格式时必须同步内部 Flash 默认值、通信写入和生产校准流程。
- 分时读取逻辑不应改成一次性阻塞读取，除非明确评估主循环最长耗时和看门狗窗口。
